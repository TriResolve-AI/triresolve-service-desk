# Data Directory

This directory is for storing application data, datasets, and configurations.

## Contents
- **training_data/**: Training datasets for agent models
- **templates/**: Response templates for common ticket types
- **configs/**: Configuration files for agents and system settings
- **logs/**: Application logs (excluded from version control)

## Notes
- Sensitive data should never be committed to version control
- Use `.env` files for secrets and credentials
- Large datasets should be referenced externally or stored in cloud storage
